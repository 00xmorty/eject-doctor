# v0.1.0

Draft release checkpoint for Eject Doctor.

## Included
- Read-only `eject-doctor.zsh` CLI.
- `list`, `doctor`, `sample`, `help`, and `--version` commands.
- macOS GitHub Actions smoke test.
- Safety model: no sudo, no kill, no unmount/eject, no force eject.
